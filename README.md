# Program IoT Devices

This repository contains a structured collection of IoT programming exercises, practice work, revision notes, and challenge tasks organized by week.

It is designed to support hands-on learning in the development of connected devices, embedded programming concepts, and practical problem solving around real-world IoT systems.

## Repository Structure

- `Week - 1` – introductory material and early exercises
- `Week - 2` – continued learning and practical tasks
- `Week - 3` – more advanced concepts and implementation work
- `Week - 4` – project-based learning and device programming practice
- `Week - 5` – deeper exercises and application development
- `Week - 6` – final weekly tasks and consolidation work
- `Practice` – extra exercises for reinforcing key topics
- `Challenges` – optional or advanced problem-solving tasks
- `Revision` – review materials and revision-focused content

## Learning Goals

- Understand the fundamentals of IoT device programming
- Build confidence with coding exercises and practical examples
- Explore connected device concepts through structured tasks
- Strengthen problem-solving by working through weekly assignments and challenges

## Recommended Workflow

1. Start with the weekly folders in order.
2. Complete the related practice exercises to reinforce learnings.
3. Use the revision folder to review important concepts.
4. Attempt the challenge tasks to extend your understanding.

## Getting Started

```bash
git clone https://github.com/M-Sherif07/Program-IoT-Devices.git
cd Program-IoT-Devices
```

Then browse the relevant folder for the current topic or week.

## Notes

This repository is intended as a learning and coursework resource. It is best used in sequence, beginning with the earliest week and progressing through the more advanced folders.
